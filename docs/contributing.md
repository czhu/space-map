# Contributing

Use the [repository contribution guide](https://github.com/czhu/space-map/blob/master/CONTRIBUTING.md)
for development setup, issue reports, and pull requests. Contributions use the
project's [PolyForm Noncommercial License 1.0.0](https://github.com/czhu/space-map/blob/master/LICENSE).

## Documentation changes

Keep scientific claims consistent with the [published paper](https://doi.org/10.1038/s41592-026-03310-8)
and distinguish study results from current software behavior. Check examples
against the implementation and keep raw data, processed data, and software
release metadata distinct. Do not introduce generic runtime, accuracy, or
hardware claims from illustrative examples.

See [Building the Documentation](BUILDING.md) for local preview and validation.
